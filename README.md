# WallpaperFeed 壁纸工具

一个用纯 C++ / Win32 编写的 Windows 壁纸工具，自带图形主界面，无第三方依赖、无需安装运行时（静态链接 CRT，单文件可执行）。

壁纸来自 [wallpaperfeed.com](https://wallpaperfeed.com)，全部免费且无需注册。

## 功能

### 主界面

| 页面 | 说明 |
|---|---|
| 发现 | 瀑布流无限加载，向下滚动到底自动追加下一页内容（来源队列：本周趋势、最新上传、最高下载、27 个分类、从站点抓取的 60 个标签，共 90 个列表页，随机洗牌并自动去重） |
| 分类 | 27 个分类胶囊（自然风景、动漫、赛博朋克、汽车、太空……），点击即切换；每个分类用 `/category/<slug>?page=N` 与同名 `/tag/<slug>?page=N` 交替无限翻页，滚到底自动加载下一页，单个分类可加载到 200 张以上 |
| 我的收藏 | 收藏的壁纸集中展示，收藏关系持久化在 `favorites.txt`，重启不丢；取消收藏会同时删掉本地那份高清备份 |
| 设置 | 自动更换间隔、开机启动、切换提示、壁纸质量、存储管理、本地数据、关于（**不再包含显示模式**，模式改由卡片/预览上的图标决定，自动换图的模式在托盘菜单里设置） |

侧栏左下角实时显示：显示器台数、收藏数量、**本地数据占用**（不足 1 GB 显示 MB，超过 1 GB 显示 GB，每约 5 秒刷新一次）。
侧栏顶部只有产品名，**没有 logo 图形**。

界面细节：

- 深色主题，全部 GDI+ 自绘（无原生控件），PerMonitorV2 高 DPI 适配
- 卡片显示缩略图、标题、原图分辨率；缩略图走 WIC 解码（支持站点使用的 WebP），本地缓存不重复下载
- **鼠标移到卡片上**：出现蓝色描边、右上角心形收藏按钮、图片底部悬浮操作条
- **收藏即落盘**：点下心形后，后台线程立刻按 1920×1080 下载一张高清 JPEG 存到 `wallpapers\fav\fav_<id>.jpg`；
  启动时会把 `favorites.txt` 里还没有本地文件的收藏补齐（失败自动重试一次）。收藏图不受自动清理影响（可在设置里改）
- **切页不再空白**：列表请求失败会重试 3 次而不是直接判定「到底」，切页后保留内容源队列，
  列表为空时显示「正在加载壁纸…」提示，并有定时兜底重试
- **缩略图失败自动处理**：单张缩略图下载失败会间隔重试，累计 3 次仍失败就把这张从列表里移除，不再留一个「缩略图不可用」的灰色块
- **滚动不压标题**：列表区有独立裁剪区，卡片向上滚动到顶部就裁掉，标题、刷新按钮、分类胶囊始终可见
- **操作条按屏幕数量动态生成图标**：1 屏只显示「应用到桌面」；2 屏显示「显示器 1 / 显示器 2 / 跨屏合一 / 复制双屏」四个图标按钮；3 屏以上最多显示 3 个单屏按钮 + 合一 + 复制
- **点击卡片打开预览浮层**：下载 1600×900 大图铺满显示，底部有心形收藏、打开原站，以及同一套按屏数生成的应用图标；`Esc` 或点击空白关闭
- 自绘滚动条，支持滚轮、拖动滑块、`PageUp/PageDown/Home/End`
- 底部 toast 提示（已收藏、已应用、失败原因等）

## 使用

1. 双击 `bin\WallpaperFeed.exe`，托盘出现图标。
2. 双击托盘图标（或启动时加 `--ui` 参数）打开主界面。
3. 在「发现」页滚动浏览，鼠标移到喜欢的图上选「应用到显示器 1 / 2 / 跨屏合一 / 复制双屏」。
4. 点卡片打开大图预览，左下角心形收藏；收藏的同时会把高清图存到 `wallpapers\fav\`。
5. 「设置」页调整更换间隔、开机启动、存储上限与自动清理规则（显示模式只在托盘菜单里设，卡片上的图标随时可以临时指定怎么铺）。
6. 侧栏左下角可以随时看到本地数据占用了多少，超上限会有托盘气泡提醒。

取消收藏时，`wallpapers\fav\` 里对应的那张高清图会一起删掉；
程序每次启动还会扫一遍该目录，把 `favorites.txt` 里已经不存在的孤儿文件清掉。

首次启动后约 8 秒自动换一次壁纸；之后按设定间隔轮换。
关闭主界面窗口只是隐藏到托盘，程序继续在后台工作；要彻底退出请用托盘菜单的「退出」。

## 配置文件

首次运行会在 exe 同目录生成 `config.ini`（UTF-8）：

```ini
mode=different            # different | span | clone
interval_minutes=60       # 0 = 关闭定时
autostart=0
show_tips=1
source=trending           # trending | new | popular | category | tag | custom
category=landscapes       # 当 source=category 时生效
tag=nature                # 当 source=tag 时生效（例如 tag=cyberpunk）
custom_url=               # 当 source=custom 时生效，填列表页完整地址
keep_files=40
jpeg_quality=92
request_cap_width=5120    # 单次下载的最大宽度，越小越省流量
auto_clean=1              # 是否自动清理旧壁纸（1/0）
keep_favorites=1          # 清理时是否保留收藏的壁纸（1/0）
keep_days=30              # 只保留最近几天下载的壁纸，0 = 不按天数清理
max_cache_mb=1024         # 壁纸数据占用上限（MB），0 = 不限制
```

界面和菜单能改的项目会立即写回配置；`tag` 和 `custom_url` 需要手动编辑后重启程序。

收藏记录在 `favorites.txt`（每行一条，制表符分隔：`id / 宽 / 高 / 缩略图地址 / 详情页 / 标题`），
收藏的高清图备份在 `wallpapers\fav\`。

## 存储管理

主界面侧栏左下角常驻显示「本地占用」，数值 = `wallpapers\`（不含 fav）+ `thumbs\` 的实际字节数。

「设置 → 存储管理」里可以：

| 项目 | 说明 |
|---|---|
| 当前占用 / 上限 | 实时显示当前字节数与设定上限 |
| 立即清理 | 按下面的规则立刻跑一遍清理，并用 toast 报告结果 |
| 自动清理旧壁纸 | 关掉后程序不再自动删文件，只保留占用提示 |
| 保留收藏的壁纸 | 开启时 `wallpapers\fav\` 里的收藏备份不会被清理 |
| 保留最近 | 7 天 / 30 天 / 90 天 / 永久，超期文件会被删除 |
| 最大占用 | 256 MB / 512 MB / 1 GB / 2 GB / 不限；超过上限时从最旧的文件开始删，直到降到上限的 90% |

清理时机：启动时跑一次；每次自动换壁纸后跑一次（内部 10 分钟节流）；
清理后仍超上限（例如收藏图本身就超了），会弹一次托盘气泡「存储空间提醒」，同一提醒 1 小时内不重复。
当前正在桌面上使用的壁纸文件不会被删。

## 壁纸源接口

工具从 wallpaperfeed.com 的公开页面抓取，逻辑如下：

1. 抓取列表页（`/trending`、`/new`、`/popular`、`/category/<slug>`、`/tag/<name>`），
   解析卡片中的 `data-wallpaper-id`、详情页地址、原图宽高和缩略图地址。
   分类页支持 `?page=N`（每页 32 张且互不重复），程序按 `category?page=N` 与 `tag?page=N` 交替往后翻；
   「发现」页则靠多个列表页排队 + 去重来实现无限滚动。
2. 缩略图直接用站点的 `/uploads/thumbnails/*.webp`（约 30 KB，300 ms 级），
   用 WIC 解码为 BGRA 后交给 GDI+ 绘制。
3. 应用壁纸时用 `POST https://wallpaperfeed.com/api/download.php`
   （参数 `wallpaper_id`、`mode=rescale`、`width`、`height`，必须带 `Referer`）直接拿到
   **指定分辨率的 JPEG**，避免下载 8K 的 WebP 原图（Windows 壁纸也不支持 WebP）。
4. 下载后用 GDI+ 做等比裁切（cover），保证不同比例/分辨率都不变形、不留黑边；跨屏合一在虚拟桌面矩形上先合成一张再按各屏切分。

## 重新编译

需要 Visual Studio 的「使用 C++ 的桌面开发」组件（MSVC + Windows SDK）。
仓库里不含 `src/res/app.ico`（二进制），`build.ps1` 会先编译 `tools/icon_gen.cpp` 现场生成图标，再编译资源与主程序：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

脚本会把源码复制到 `%TEMP%\wallpaperfeed_build`（避开 rc.exe 对中文路径的兼容问题），
依次编译图标生成器、生成 `app.ico`、编译资源、编译主程序，最后输出到 `bin\`。

编译选项：`/O2 /MT /std:c++17 /utf-8`，静态链接 CRT，因此拷到任何 Windows 10/11 x64 机器上都能直接运行。

依赖的系统库：`user32 gdi32 gdiplus shell32 ole32 oleaut32 uuid winhttp advapi32 comctl32 windowscodecs dwmapi`（全部为系统自带）。

## 说明与排查

- **托盘图标被折叠**：Win11 默认把新图标放进「隐藏的图标」区，可拖到任务栏常驻。
- **换壁纸后图标闪一下**：`IDesktopWallpaper` 会重建 `TranscodedWallpaper`，属正常现象。
- **混合 DPI 的双屏**：程序以 PerMonitorV2 运行，坐标与分辨率取自系统；若两屏缩放比例不同且跨屏合一效果不理想，建议改用「每屏不同」。
- **缩略图加载失败**：会自动重试，累计 3 次仍失败就把这张从列表里移除（站点有些老图只有占位图，属于正常淘汰）；
  整批都加载不出来时，可在设置页清理缩略图缓存后重新加载。
- **分类只加载到 30~50 张就「到底」**：v1.3 已改为 `?page=N` 翻页，滚到底会继续加载下一页，单分类实测可到 200 张以上；
  某一类如果 `/tag/<slug>` 没有同名标签页（站点返回 404），程序只会跳过这一路，不影响 `/category` 继续翻页。
- **系统设成「复制这些显示器」**：Windows 会把两块物理屏合并成一个逻辑屏，`IDesktopWallpaper` 只认 1 台显示器。
  这时卡片上只显示一个「应用到桌面」按钮；就算在扩展模式下点了「显示器 2」，程序也会自动改成设置整个桌面，不会再报「显示器索引无效」。
  `WM_DISPLAYCHANGE` 会让界面立刻重新探测屏数，卡片上的图标数量跟着变。
- **切换分类/发现时短暂空白**：正常，切页后要重新拉列表，界面会显示「正在加载壁纸…」；
  若超过 5 秒仍为空，程序会自己再发一次请求，也可点右上角「刷新」。
  （v1.2.1 修掉了「列表线程被缩略图线程抢走唤醒信号」的竞态，现在任何分类都能正常加载。）
- **列表滚动时压住标题**：v1.3 修掉了 `DrawCover` 里 `SetClip/ResetClip` 把列表裁剪区一起清空的问题，
  卡片只会滚到列表区上边缘就被裁掉，标题、刷新按钮、分类胶囊不会被盖住。
- **点标题栏却点到了下面的卡片**：v1.3.1 给每个热区记了「所属裁剪区上边界」，滚到标题栏下方被裁掉的卡片/设置项不再参与命中测试，
  点击标题、刷新、分类胶囊只会触发它们自己。
- **抓取失败**：日志会记录 HTTP 状态。站点结构调整时，`wf.cpp` 里的解析规则可能需要同步更新。
- **无网络**：切换会失败并 3 分钟后重试，原壁纸保持不变。

## 卸载

托盘菜单退出程序 → 关闭「开机自动启动」→ 删除整个 `bin` 目录即可，不写系统其它位置。
